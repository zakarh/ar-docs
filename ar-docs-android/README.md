# ar-docs
AR Docs: Augmented Reality Documents

An Android app to view documents and images in augmented reality.

Demo Video available on [YouTube](https://youtu.be/sQUqk9db76Y) (2-minutes).

Demo App available on the [Google Play Store](https://play.google.com/store/apps/details?id=com.blastrock.ardocs).

Refer to the design doc for a simple overview of the project.

## Technologies

Project is created with:

- Android
- Java
- ARCore
- Python 3
- Firebase

Useful Tools:

- Postman: [https://www.postman.com](https://www.postman.com/)

## Features

### Supported File Types

- IMAGES: JPG, JPEG, PNG
- DOCUMENTS: PDF
