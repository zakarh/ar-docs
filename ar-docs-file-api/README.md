# docs-api

This project converts documents and images into GLTFs.

It was developed specifically for [ar-docs](https://github.com/zakarh/ar-docs).

Refer to the design doc for a simple overview of the project.

## Technologies

Project is created with:

- Python 3
- Blender
- Node.js
- Poppler
- Firebase

Useful Tools:

- Postman: [https://www.postman.com](https://www.postman.com/)

## Features

### Functionality

- INPUT: Images (JPG, JPEG, PNG), Documents (PDF)
- OUTPUT: GLTF

## Setup

To run this project locally or to deploy to a cloud platform you will need Docker. Once, installed you can build the **Dockerfile** and run the project if you so desire.

- Install Docker: [https://docs.docker.com/get-docker](https://docs.docker.com/get-docker/)
